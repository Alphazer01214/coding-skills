# CHECKLIST — 成稿验收清单

供 `doc-style` Phase 3–4 使用。每项：位置（段落/行）→ 问题 → 已改 / 保留（注明理由）。

## A. 降 AI 味（优先）

| # | 检查 | 通过标准 |
|---|------|----------|
| A1 | 长句套叠 | 单句 ≤40 字；>30 字句语义明确 |
| A2 | 被动语态 | 无「被/受到/由…进行」滥用，可改主动的都已改 |
| A3 | 双重否定 | 无「不…不能…」类绕圈 |
| A4 | 形容词堆砌 | 名词前修饰 ≤2 层，长定语已拆句 |
| A5 | 代词指代 | 「其/该/此/这」均唯一可回指 |
| A6 | 中英粘连 | 中文与英文/数字间有半角空格（或全文统一无空格） |
| A7 | 标点全半角 | 中文句内无半角标点（时间 `8:00`、代码除外） |
| A8 | 感叹号 | 无 `！` 连用；正文尽量零感叹号 |
| A9 | 省略号 | 用 `⋯⋯`；无 `...`/`。。。`；不与「等」同用 |
| A10 | 一逗到底 | 段内长串逗号已拆句 |
| A11 | 段落形态 | 一段一主题；中心句在段首；≤7 行 |
| A12 | 标题形态 | 无跳级、无孤立编号、下级不重复上级名 |

## B. 格式正确性

| # | 检查 | 通过标准 |
|---|------|----------|
| B1 | 数字半角 | 无全角数字 `０-９` |
| B2 | 千分位 | 五位数以上有千分号 |
| B3 | 数值范围 | 用 `～`/`—`/「至」；两端带单位 |
| B4 | 增减表述 | 「增加了/增加到」用对；无「降低 N 倍」 |
| B5 | 的地得 | 形+的+名；副+地+动；动+得+副 |
| B6 | 顿号并列 | 中文句内并列用 `、`；末项「和」连接 |
| B7 | 引号括号 | 中文全角 `“ ”` `（）`；套引外双内单 |
| B8 | 句末括号 | 句号在括号外：`（见第 26 页）。` |
| B9 | 行首点号 | 行首无 `。，、；：` |
| B10 | 标题点号 | 标题末尾无 `。，、；：` |
| B11 | 英文处理 | 首次出现有中文标注；专有名词大写正确 |
| B12 | 文件名 | 小写、半角、`-` 分隔、无空格、无中文 |

## C. 边界纪律

| # | 检查 | 通过标准 |
|---|------|----------|
| C1 | 信息守恒 | 未新增/删减事实、数据、因果 |
| C2 | 结构守恒 | 未擅自重组章节/论证（Phase 1 列出的结构违规除外） |
| C3 | 代码/引文 | 代码块、外语段落、引用原文未改 |
| C4 | 技术内容 | 未改技术语义、参数、命令 |

## 输出格式

```text
## 摘要
- 改了什么：…
- 没改什么：…
- 残留风险：…（或「无」）
```
