本文件是 agent 在本项目中的**边界清单**。条目可单独检查；与仓库其他文档冲突时，以本文件为准（或在此显式让位于某一文档）。

## 使用方式

- Agent 在改文件、跑命令、提交之前应先对照相关条目。
- 人类评审 agent 行为时可引用条目编号（如 `G1`、`Q2`）。
- 修订时保留有效条目；废弃条目可移到文末「已废弃」并注明替代条目。
